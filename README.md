# 📢 Website

> Esta branch reúne o site expositivo do M.E.R.LIN, criado especialmente para divulgação, apresentando seus principais recursos de forma clara, objetiva e visualmente atraente.
> 
<br>

## 🤔 Por que a WebVitrine?
> Nosso software principal é um aplicativo de desktop robusto, mas sabemos que muitas vezes um site bem feito ajuda muito na divulgação, apresentando o produto para novos usuários e clientes.
> A webvitrine tem o objetivo de ser uma página de apresentação para o software, focando em:

- Destacar os principais benefícios e funcionalidades.

- Facilitar o acesso para quem deseja conhecer o produto antes de instalar.

- Servir como material de apoio para demonstrar empenho no projeto.
  
- Facilitar o acesso às gravações das apresentações do M.E.R.LIN. (Footer)

<br>

## 🗂️ Estrutura de Pastas

````

/webvitrine
│
├── index.html          # Página Principal do Site
│
├── /src                # Arquivos Principais
│   ├── index.js        # Script Para Efeitos Visuais 
│   ├── style.css       # Estilização do Site
│   └── /assets         # Arquivos Complementares
│       ├── /fonts      # Fontes Utilizadas no Site
│       └── /imgs       # Imagens Usadas
````
